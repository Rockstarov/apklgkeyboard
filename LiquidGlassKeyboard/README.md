# Liquid Glass Keyboard

Android-клавиатура (InputMethodService) в стиле «жидкого стекла». Без сторонних библиотек: всё рисуется на Canvas.

## Что умеет

- Стеклянные клавиши: градиент, блик по верхней кромке, переливающаяся рамка, мягкая тень
- «Жидкое» световое пятно, которое растекается от точки касания; клавиша слегка продавливается
- Размытие фона под клавиатурой (blur-behind, Android 12+). Если устройство его не поддерживает, остаётся полупрозрачное стекло
- Светлая и тёмная тема (следует за системной)
- Раскладки: русская (ЙЦУКЕН), английская (QWERTY), цифры и символы
- Мультитач, haptic-отклик, автоповтор Backspace при удержании
- Shift: одиночное нажатие, двойное — Caps Lock, автозаглавная в начале предложения
- Долгое нажатие на верхний ряд — цифра (на «е» — «ё»)
- Долгое нажатие на значок глобуса — выбор другой клавиатуры; короткое — смена языка (RU/EN)
- Для полей email / URL / пароль включается английская раскладка, для числовых и телефонных — символы

## Как получить APK

### Вариант 1. Android Studio
1. File → Open → выберите папку проекта.
2. Дождитесь синхронизации Gradle.
3. Build → Build APK(s). Файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. Командная строка (нужны JDK 17 и Android SDK)
```
./gradlew assembleDebug
```

### Вариант 3. Облачная сборка без установки SDK
1. Создайте репозиторий на GitHub и загрузите в него содержимое папки.
2. Откройте вкладку Actions → Build APK → Run workflow.
3. По окончании скачайте артефакт `LiquidGlassKeyboard-debug-apk` — внутри `app-debug.apk`.

## Установка на телефон
1. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).
2. Откройте приложение «Liquid Glass Keyboard».
3. Нажмите «Открыть настройки» и включите клавиатуру.
4. Нажмите «Выбрать клавиатуру» и выберите Liquid Glass.

## Структура

- `app/src/main/java/com/liquidglass/keyboard/GlassKeyboardView.kt` — отрисовка и обработка касаний
- `app/src/main/java/com/liquidglass/keyboard/LiquidKeyboardService.kt` — сервис клавиатуры, ввод текста, blur окна
- `app/src/main/java/com/liquidglass/keyboard/MainActivity.kt` — экран настройки

Настройки внешнего вида (высота клавиш, радиус, прозрачность) находятся в начале `GlassKeyboardView.kt` и в функциях `buildPanel()` / `buildShaders()`.
